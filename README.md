This is the official [Homebrew](https://brew.sh) tap for Artifact Keeper tools.

## Installation

```bash
brew install artifact-keeper/tap/ak
```

## Available Formulae

| Formula | Description |
|---------|------------|
| `ak` | CLI/TUI tool for Artifact Keeper — an enterprise artifact registry |

## Updating

```bash
brew update
brew upgrade ak
```
